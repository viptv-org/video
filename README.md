# VIPTV video

React and web-TV video controller for VIPTV. It was independently imported from `get-air/video` at `a6a5650abe3e906d201ef92d02f55b8d32d323cb`; source history and the Apache-2.0 and MIT license texts remain intact.

The controller supports direct HTML playback, Samsung Tizen AVPlay, webOS/Vizio adapters, React integration, and explicit fallback ordering. It is the shared TypeScript playback interface for web, web-based TV clients, and Tauri through `viptv-org/tauri-video-plugin`.

Inherited workflows and release commands were removed. Run `npm run check` and `npm run build` locally.
